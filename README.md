# 🌐 Login & Registration Website

A modern and responsive website with integrated login and registration forms built using **HTML**, **CSS**, and **JavaScript**. Designed with a clean UI and animated form transitions.

---

## ✨ Features

- ✅ Responsive Header Navigation
- 🔐 Login and Registration Forms
- 🎨 Animated Popup Modal
- 🧠 Client-Side Validation Ready
- 🧩 Ionicons Integration for Stylish Icons
- ⚡ Toggle Between Login and Registration Forms

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- [Ionicons](https://ionic.io/ionicons) (Icon Library)
